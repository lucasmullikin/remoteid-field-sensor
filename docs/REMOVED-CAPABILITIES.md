# Removed capabilities

This file is the audit trail for the no-jamming constraint.

Some open-source drone tooling ships offensive capability alongside receiving capability.
Where this project adopts code from such a project, the offensive capability is removed
before adoption, and the removal is recorded here.

## Format

Each entry records: the upstream project, the capability removed, the files or functions
affected, and the commit in this repository that performed the removal.

| Upstream project | Capability removed | Files / functions | Commit |
|---|---|---|---|
| _(none adopted yet)_ | | | |

**This table is empty because no third-party code has been adopted yet.**
It is published now so the commitment is on the record before the first adoption, not
after.
